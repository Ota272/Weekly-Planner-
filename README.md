# ✅ Weekly Planner

### Plan. Act. Achieve.

A beautiful, feature-rich weekly planner web application for organizing your days, managing tasks, and visualizing ideas — all in your browser.

## ✨ Features

🗓 **Weekly Schedule** — Plan your entire week at a glance with a clean 7-day grid layout. Each day shows tasks sorted by time with color-coded categories.

🗺 **Interactive Mind Map** — Click any task to open a detailed view with an interactive mind map of subtasks. Pan, zoom, and navigate freely.

✅ **Smart Subtasks** — Add subtasks directly on the mind map or via a list. Toggle completion with a single click — changes are instant.

🎨 **Drawing Board** — A full-featured canvas for sketching ideas, diagrams, and notes. Includes pen, eraser, color picker, and brush size controls.

📆 **Monthly Calendar** — Overview your month with task previews on each day. Navigate between months easily.

💾 **Auto-Save** — All data is automatically saved to your browser's localStorage. No account needed, no data leaves your device.

📱 **Modern UI** — Clean, premium design with smooth animations, glassmorphism effects, and the Inter font family.

## 🚀 Quick Start

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher)

### Installation

```bash
# Clone the repository
git clone https://github.com/Ota272/Weekly-Planner-.git
cd Weekly-Planner-

# Install dependencies
npm install

# Start development server
npm run dev
```

Open **http://localhost:5173** in your browser.

### Build for Production

```bash
npm run build
```

The optimized output will be in the `dist/` folder, ready for deployment.

## ✨ Возможности

🗓 **Расписание на неделю** — Планируйте всю неделю на одном экране с удобной сеткой из 7 дней. Задачи отсортированы по времени и помечены цветовыми категориями.

🗺 **Интерактивная карта задач** — Нажмите на задачу, чтобы открыть детальный вид с интерактивной mind map подзадач. Двигайте, приближайте и удаляйте карту.

✅ **Умные подзадачи** — Добавляйте подзадачи прямо на карте или через список. Отмечайте выполнение одним кликом — изменения мгновенные.

🎨 **Доска для рисования** — Полноценный холст для скетчей, диаграмм и заметок. Кисть, ластик, палитра цветов и настройка толщины.

📆 **Календарь на месяц** — Обзор месяца с превью задач на каждый день. Удобная навигация между месяцами.

💾 **Автосохранение** — Все данные автоматически сохраняются в localStorage браузера. Без регистрации, данные не покидают ваше устройство.

📱 **Современный дизайн** — Чистый, премиальный интерфейс с плавными анимациями и шрифтом Inter.
